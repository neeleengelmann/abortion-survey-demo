jsPsych files, hosted with the survey so it doesn't depend on an external site.

jsPsych 8.0.3 (jspsych.js, jspsych.css) and plugins 2.0.0 (plugin-*.js), the versions the
Arabic pilot ran on. Copied unchanged from unpkg.com:
  https://unpkg.com/jspsych@8.0.3/dist/index.browser.min.js   -> jspsych.js
  https://unpkg.com/jspsych@8.0.3/css/jspsych.css             -> jspsych.css
  https://unpkg.com/@jspsych/plugin-<name>@2.0.0/dist/index.browser.min.js -> plugin-<name>.js

jsPsych is MIT-licensed (https://github.com/jspsych/jsPsych). The same files are in the
EN, ES and AR folders.
